# Inkstamp Map — feedback

Bug reports, feature ideas and privacy requests for **[inkstampmap.com](https://inkstampmap.com)**.

This repository only hosts issues: the source code is private.

## Open an issue

- 🐛 [Report a bug](../../issues/new?template=bug_report.yml)
- 💡 [Suggest a feature or a missing stamp](../../issues/new?template=feature_request.yml)
- 🔒 [Privacy / personal data request](../../issues/new?template=privacy_request.yml)

⚠️ Issues are **public**. Never post your email address, password, payment details or any other personal data here.
To delete your account and all its data, use **Account → Delete account** on the site.
